# Share rendering policy

Matrix now shares relation descriptions, reaction previews, attribution precedence and destination binding rules. Text and media captions enforce final budgets after prefix and relation composition. Native edits reject oversized bodies and ambiguous targets; secondary relation descriptions are retained without changing the authorized native target.

Authored messages carrying reaction context retain their body. Readable reply context takes priority in constrained fallback presentation without changing the stored relation tuple.

Native mutations also require a matching event kind and relation. Ordinary
messages cannot become native edits or redactions merely by carrying a mutation
relation, and relation-free mutation events cannot become ordinary native sends.
